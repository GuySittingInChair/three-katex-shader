# Glossary

One line per word, in alphabetical order, with a link to the page that explains it. Pages marked
*(planned)* don't exist yet; until then the link goes to the closest page that does.

- **actions**: extra buttons a sketch adds to the Params panel, like "Poke the dish". → [sketch-format.md](sketch-format.md)
- **additive blending**: overlapping light adds up and gets brighter, like overlapping torch beams. → [colour-blending-and-gain.md](colour-blending-and-gain.md)
- **aggregation**: things clumping together and sticking. → [sketches/diffusionLimitedAggregation.md](sketches/diffusionLimitedAggregation.md)
- **alpha**: a colour's fourth number, how solid it is: 1 solid, 0 invisible. → [rgb.md](rgb.md)
- **array**: a numbered list of values, written `[ ]`, counting from 0. → [js-arrays-and-objects.md](js-arrays-and-objects.md)
- **async / await**: marks a recipe that can pause to wait for a download without freezing the page. → [js-promises-and-fetch.md](js-promises-and-fetch.md)
- **attribute**: a list holding one value per corner of a shape (position, colour). → [mesh-geometry-material.md](mesh-geometry-material.md)
- **bell curve**: the hill shape of heights, exam marks and errors: most near the middle, few at the edges. → [sketches/galtonBoard.md](sketches/galtonBoard.md)
- **Bézier curve**: a smooth curve pulled towards a few control points, as in drawing programs. → [sketches/bezierDeCasteljau.md](sketches/bezierDeCasteljau.md)
- **bifurcation**: the moment one steady behaviour splits into two, like a population starting to boom and bust. → [sketches/bifurcationDiagram.md](sketches/bifurcationDiagram.md)
- **binary file (`.bin`)**: numbers packed as raw bytes to keep downloads small. → [js-promises-and-fetch.md](js-promises-and-fetch.md)
- **binomial distribution**: how often you get each number of heads from a set of coin flips. → [sketches/galtonBoard.md](sketches/galtonBoard.md)
- **bloom**: another name for glow. → [glow.md](glow.md)
- **burn-in**: running a rule many times and throwing the results away, so it settles first. → [sketches/bifurcationDiagram.md](sketches/bifurcationDiagram.md)
- **camera**: the viewpoint the 3D scene is photographed from. → [scene-and-camera.md](scene-and-camera.md)
- **CanvasTexture**: a picture drawn on a hidden flat canvas, then used in the scene. → [textures.md](textures.md)
- **category**: the gallery shelf a sketch sits on. → [sketch-format.md](sketch-format.md)
- **catenoid**: the hourglass-shaped soap film stretched between two rings held apart. → [sketches/helicoidCatenoid.md](sketches/helicoidCatenoid.md)
- **caustic**: bright lines of light focused by a curved surface, like sunlight on a pool floor. → [sketches/causticsLight.md](sketches/causticsLight.md)
- **cellular automaton**: a grid of squares that each update by a simple rule about their neighbours. → [sketches/gameOfLife.md](sketches/gameOfLife.md)
- **chaos**: behaviour that never settles and where tiny changes lead to completely different results. → [sketches/bifurcationDiagram.md](sketches/bifurcationDiagram.md)
- **clamp**: keep a number between a lowest and highest value. → [glsl-basics.md](glsl-basics.md)
- **Clifford torus**: the perfectly balanced doughnut in the Hopf fibration, where every pair of its circles links once. → [sketches/hopfFibration.md](sketches/hopfFibration.md)
- **colour scale**: a rule turning a measured number into a colour you can read back. → [colour-scales.md](colour-scales.md)
- **comedy formula**: a true equation × an absurd noun, told deadpan (`src/lib/bit.js`). → [comedy-captions.md](comedy-captions.md)
- **comment**: a note for people, after `//` or between `/*` and `*/`, ignored by the computer. → [js-values-and-variables.md](js-values-and-variables.md)
- **complex number**: two numbers bundled together, like a position across and up, that can be multiplied. → [sketches/audioReactiveJulia.md](sketches/audioReactiveJulia.md) (math page *(planned)*)
- **connectome**: a wiring diagram of a brain: every neuron and who it talks to. → [sketches/flyConnectome.md](sketches/flyConnectome.md)
- **const / let**: make a named value; `const` never changes, `let` can. → [js-values-and-variables.md](js-values-and-variables.md)
- **control point**: a point that pulls a curve towards it without the curve passing through it. → [sketches/bezierDeCasteljau.md](sketches/bezierDeCasteljau.md)
- **cosine palette**: the one-line rainbow recipe: red, green and blue each rise and fall, out of step. → [cosine-palette.md](cosine-palette.md)
- **ctx**: the bag of useful things the app hands a sketch: camera, scene, sliders, time. → [frame-loop.md](frame-loop.md)
- **damping**: losing a little speed every step, like moving through honey, so things settle. → [sketches/forceDirectedGraph.md](sketches/forceDirectedGraph.md)
- **DataTexture**: a grid of numbers made in code and handed to a shader as a picture. → [textures.md](textures.md)
- **delta (`ctx.delta`)**: seconds since the last frame, about 0.017. → [frame-loop.md](frame-loop.md)
- **destructuring**: taking several named values out of an object in one line, `const { a, b } = …`. → [js-arrays-and-objects.md](js-arrays-and-objects.md)
- **diffusion**: spreading out from where there is more to where there is less, like ink in water. → [sketches/belousovZhabotinsky.md](sketches/belousovZhabotinsky.md)
- **dispose**: the clean-up step when you leave a sketch. → [frame-loop.md](frame-loop.md)
- **diverging scale**: a colour scale with two colours meeting at a pale middle, for "above or below average". → [colour-scales.md](colour-scales.md)
- **domain warping**: looking up noise at a position that has itself been pushed by noise; makes fake fluids. → [sketches/fluidDye.md](sketches/fluidDye.md)
- **edge (graph)**: a link between two dots in a network. → [sketches/forceDirectedGraph.md](sketches/forceDirectedGraph.md)
- **emergence**: order arising from simple local rules, with no leader. → [sketches/boidsFlock.md](sketches/boidsFlock.md)
- **escape time**: how many rounds of a rule a point survives before flying off; it colours most fractals. → [sketches/audioReactiveJulia.md](sketches/audioReactiveJulia.md)
- **Euler's method**: the simplest way to step a simulation forward: new value = old value + speed × time step. → [sketches/kuramotoSivashinsky.md](sketches/kuramotoSivashinsky.md)
- **excitable**: quiet until sparked, then it fires a wave and needs time to recover. → [sketches/belousovZhabotinsky.md](sketches/belousovZhabotinsky.md)
- **fbm**: noise stacked in layers, each twice as detailed and half as strong. → [noise.md](noise.md)
- **fetch**: ask for a file over the network. → [js-promises-and-fetch.md](js-promises-and-fetch.md)
- **field**: one labelled box in a sketch file, like `name` or `update`. → [sketch-format.md](sketch-format.md)
- **flat shading**: lighting each triangle as one flat face, for a cut-gem look. → [sketches/displacedIcosphere.md](sketches/displacedIcosphere.md)
- **float**: in GLSL, one number with a decimal point; write `1.0`, not `1`. → [glsl-basics.md](glsl-basics.md)
- **force-directed layout**: drawing a network by letting dots repel and links pull like springs. → [sketches/forceDirectedGraph.md](sketches/forceDirectedGraph.md)
- **Fourier transform**: splitting a pattern into a mix of plain waves, like an equaliser splits music into bass and treble. → [sketches/kuramotoSivashinsky-fix.md](sketches/kuramotoSivashinsky-fix.md)
- **fractal**: a shape with detail at every zoom level, often made by repeating one simple step many times. → [sketches/lifeWarpedFractal.md](sketches/lifeWarpedFractal.md)
- **fragment shader**: the shader that picks the colour of each pixel. → [shaders.md](shaders.md)
- **frame**: one picture of the animation; about 60 are drawn each second. → [frame-loop.md](frame-loop.md)
- **Fresnel effect**: surfaces seen edge-on reflect more than surfaces seen face-on, like a lake at a low angle. → [sketches/iridescentSphere.md](sketches/iridescentSphere.md)
- **function**: a named, reusable recipe with inputs and a result. → [js-functions.md](js-functions.md)
- **gain**: multiplying brightness up, like a microphone's gain knob. → [colour-blending-and-gain.md](colour-blending-and-gain.md)
- **Gaussian curvature**: how strongly a surface curves at a spot, in a way bending without stretching can't change. → [sketches/helicoidCatenoid.md](sketches/helicoidCatenoid.md)
- **geometry**: an object's shape, as corners and triangles. → [mesh-geometry-material.md](mesh-geometry-material.md)
- **glider**: a five-square pattern in the Game of Life that crawls diagonally forever. → [sketches/gameOfLife.md](sketches/gameOfLife.md)
- **glow**: blurring the brightest parts of the picture and adding them back, so bright things shine. → [glow.md](glow.md)
- **GLSL**: the language shaders are written in. → [glsl-basics.md](glsl-basics.md)
- **golden angle**: about 137.5°, the turn that spaces sunflower seeds; used so loops never repeat exactly. → [sketches/belousovZhabotinsky.md](sketches/belousovZhabotinsky.md)
- **graph (network)**: dots joined by links, like a metro map. → [sketches/forceDirectedGraph.md](sketches/forceDirectedGraph.md)
- **hash**: a scrambler that turns a position into a random-looking but repeatable number. → [noise.md](noise.md)
- **helicoid**: the spiral-staircase soap film you'd get on a twisted wire. → [sketches/helicoidCatenoid.md](sketches/helicoidCatenoid.md)
- **histogram**: a bar chart counting how often each result happened. → [sketches/galtonBoard.md](sketches/galtonBoard.md)
- **Hopf fibration**: the four-dimensional sphere split into circles, every pair of them linked like chain links. → [sketches/hopfFibration.md](sketches/hopfFibration.md)
- **HSL**: a colour as hue (place on the colour wheel), saturation (vividness) and lightness. → [rgb.md](rgb.md)
- **hyperbolic geometry**: a world with more room the further out you go, like a crinkly lettuce leaf. → [sketches/hyperbolicTiling.md](sketches/hyperbolicTiling.md)
- **if / else, `? :`**: choose what to do depending on a question. → [js-decisions-and-loops.md](js-decisions-and-loops.md)
- **instancing**: drawing many copies of one shape in a single go. → [instancing.md](instancing.md)
- **integral**: in calculus, a running total; the integral of a wave is another, shifted wave. → [sketches/different-this-time.md](sketches/different-this-time.md) (math page *(planned)*)
- **interference**: waves adding up where they agree and cancelling where they don't. → [sketches/causticsLight.md](sketches/causticsLight.md)
- **iridescence**: rainbow colours that change with the angle you look from, as on a soap bubble. → [sketches/iridescentSphere.md](sketches/iridescentSphere.md)
- **isometry**: a bend that changes a shape without stretching or squashing any part of it. → [sketches/helicoidCatenoid.md](sketches/helicoidCatenoid.md)
- **JSON**: a text format of labelled values, used for `meta.json` files. → [js-promises-and-fetch.md](js-promises-and-fetch.md)
- **Julia set**: the shape of points that never fly off under the rule "square it, add c". → [sketches/audioReactiveJulia.md](sketches/audioReactiveJulia.md)
- **kaleidoscope fold**: cutting the picture into wedges and folding them all onto one. → [sketches/chatgpt-quantum.md](sketches/chatgpt-quantum.md)
- **Klein bottle**: a bottle whose inside is its outside; in three dimensions it must pass through itself. → [sketches/kleinBottle.md](sketches/kleinBottle.md)
- **Kuramoto–Sivashinsky equation**: the classic equation for a wrinkling flame front that never settles. → [sketches/kuramotoSivashinsky.md](sketches/kuramotoSivashinsky.md)
- **Laplacian (∇²)**: how different a spot is from the average of its neighbours. → [sketches/kuramotoSivashinsky.md](sketches/kuramotoSivashinsky.md)
- **LaTeX**: a way of writing math as text so it can be shown as a neat equation. → [motion-and-latex.md](motion-and-latex.md)
- **lead (aiming)**: aiming ahead of a moving target, at where it will be when the shot arrives. → [sketches/intercept.md](sketches/intercept.md)
- **leaky integrate-and-fire**: a neuron as a leaky bucket that fires when it overflows. → [sketches/flyConnectome.md](sketches/flyConnectome.md)
- **lerp / mix**: blend between two values by a fraction from 0 to 1. → [colour-blending-and-gain.md](colour-blending-and-gain.md)
- **lesion**: damage to part of a brain. → [sketches/flyConnectome.md](sketches/flyConnectome.md)
- **light**: makes solid objects look solid; directional (Sun), ambient (glow), point (bulb), spot (torch), hemisphere (sky and ground). → [lights.md](lights.md)
- **lines (fat lines)**: lines with a fixed width in pixels, from `src/lib/fatLines.js`. → [lines-and-points.md](lines-and-points.md)
- **logarithmic spiral**: a spiral that looks the same at every size, like a snail shell. → [sketches/chatgpt-quantum.md](sketches/chatgpt-quantum.md)
- **logistic map**: the simplest rule for a population that grows but crowds itself. → [sketches/bifurcationDiagram.md](sketches/bifurcationDiagram.md)
- **loop (`for`)**: repeat a block of code a set number of times. → [js-decisions-and-loops.md](js-decisions-and-loops.md)
- **material**: how a surface looks: colour, gloss, how it reacts to light. → [mesh-geometry-material.md](mesh-geometry-material.md)
- **matrix**: a block of 16 numbers storing where something is, how it is turned and how big it is. → [instancing.md](instancing.md)
- **mesh**: a visible solid object: geometry plus material. → [mesh-geometry-material.md](mesh-geometry-material.md)
- **minimal surface**: a surface as small as possible for its edges, like a soap film. → [sketches/enneperSurface.md](sketches/enneperSurface.md)
- **Möbius strip**: a strip with a half-twist taped into a loop: it has only one side. → [sketches/kleinBottle.md](sketches/kleinBottle.md)
- **mode**: `'shader'` (one flat picture) or `'3d'` (a scene). → [what-is-a-sketch.md](what-is-a-sketch.md)
- **motion**: the sketch's "time in, numbers out" recipe that drives the animation and the equation. → [motion-and-latex.md](motion-and-latex.md)
- **neuron**: a nerve cell, which collects signals and fires when they add up past a threshold. → [sketches/flyConnectome.md](sketches/flyConnectome.md)
- **node**: a dot in a network. → [sketches/forceDirectedGraph.md](sketches/forceDirectedGraph.md)
- **noise**: smooth, natural-looking randomness, like a rumpled bedsheet rather than TV static. → [noise.md](noise.md)
- **non-orientable**: one-sided: you can't paint an inside and an outside different colours. → [sketches/kleinBottle.md](sketches/kleinBottle.md)
- **normal**: the direction a bit of surface faces, needed for shading. → [mesh-geometry-material.md](mesh-geometry-material.md)
- **normalise**: shrink or stretch an arrow to length 1, keeping only its direction. → [sketches/audioReactiveMesh.md](sketches/audioReactiveMesh.md)
- **object**: a set of labelled values, written `{ }`. → [js-arrays-and-objects.md](js-arrays-and-objects.md)
- **octave**: one layer of fbm noise, twice the detail of the last (as an octave doubles a note's pitch). → [noise.md](noise.md)
- **Ollama**: a program that runs AI models on your own computer, with no internet and no account. → [getting-a-second-opinion.md](getting-a-second-opinion.md)
- **orbit controls**: drag to turn the camera around the scene's centre. → [camera-and-controls.md](camera-and-controls.md)
- **orbit trap**: a tally of how often a point passes near a chosen shape while being folded; used for colour. → [sketches/chatgpt-quantum.md](sketches/chatgpt-quantum.md)
- **orthographic camera**: a camera with no perspective; used by flat `shader` sketches. → [scene-and-camera.md](scene-and-camera.md)
- **parametric surface**: a surface made by a formula that says where each point of a flat square goes. → [sketches/enneperSurface.md](sketches/enneperSurface.md)
- **params**: a sketch's sliders. → [params.md](params.md)
- **pentatonic scale**: a five-note scale (C D E G A) in which no notes clash, like the piano's black keys. → [sketches/generativeSynth.md](sketches/generativeSynth.md)
- **perspective camera**: a camera where far things look smaller, like real life. → [scene-and-camera.md](scene-and-camera.md)
- **phase**: how far through a loop we are, from 0 to 1. → [motion-and-latex.md](motion-and-latex.md)
- **pinch point**: a spot where a surface comes to a sharp crease. → [sketches/boysSurface.md](sketches/boysSurface.md)
- **ping-pong**: drawing back and forth between two hidden pictures, one simulation tick each time. → [render-targets.md](render-targets.md)
- **pixel**: one tiny dot of the screen. → [shaders.md](shaders.md)
- **Poincaré disk**: a round map of hyperbolic space where things shrink towards a rim that's infinitely far away. → [sketches/hyperbolicTiling.md](sketches/hyperbolicTiling.md)
- **points (`THREE.Points`)**: a cloud of dots, for stars, sparks and data. → [lines-and-points.md](lines-and-points.md)
- **probability**: how likely something is, from 0 (never) to 1 (certain). → [sketches/galtonBoard.md](sketches/galtonBoard.md)
- **procedural**: made by a recipe each time it's drawn, not painted or stored. → [sketches/infernoCape.md](sketches/infernoCape.md)
- **projective plane**: the surface you'd get by gluing each edge point of a disc to its opposite; it can't be built in 3D without crossing itself. → [sketches/boysSurface.md](sketches/boysSurface.md)
- **Promise**: a ticket for a result that will arrive later. → [js-promises-and-fetch.md](js-promises-and-fetch.md)
- **proportional navigation**: homing by steering to keep the target's direction from changing. → [sketches/antiAircraftContraception.md](sketches/antiAircraftContraception.md)
- **quaternion**: how 3D programs store which way something faces. → [instancing.md](instancing.md)
- **radians**: a way of measuring angles; a full turn is about 6.28 (2π), a quarter turn about 1.57. → [scene-and-camera.md](scene-and-camera.md) (math page *(planned)*)
- **random**: see *seed*. `Math.random()` gives a fresh number between 0 and 1 each time. → [randomness.md](randomness.md)
- **random walk**: moving by random steps, like a stumbling drunk. → [sketches/diffusionLimitedAggregation.md](sketches/diffusionLimitedAggregation.md)
- **reaction–diffusion**: chemicals that react where they are and spread to their neighbours, making waves and spots. → [sketches/belousovZhabotinsky.md](sketches/belousovZhabotinsky.md)
- **rebuild (slider)**: a slider that restarts the sketch with the new value when you let go. → [params.md](params.md)
- **reflection in a circle**: a mirror that's a circle: points near its edge stay near, points deep inside are flung far out. → [sketches/hyperbolicTiling.md](sketches/hyperbolicTiling.md)
- **render target**: a hidden picture a shader can draw into instead of the screen. → [render-targets.md](render-targets.md)
- **Reynolds number**: tells you whether a swimmer lives in "honey world" (under 1) or "splashy world" (large). → [sketches/antiAircraftContraception.md](sketches/antiAircraftContraception.md)
- **RGB**: a colour as three numbers: red, green and blue. → [rgb.md](rgb.md)
- **rounding error**: the tiny mistake (about 1 part in 10 million billion) a computer makes on every sum. → [sketches/kuramotoSivashinsky-fix.md](sketches/kuramotoSivashinsky-fix.md)
- **saddle**: a surface curving up one way and down the other, like a pringle. → [sketches/enneperSurface.md](sketches/enneperSurface.md)
- **scene**: the 3D world holding every object, light and camera. → [scene-and-camera.md](scene-and-camera.md)
- **seed**: a starting number that makes "random" results come out the same every time. → [randomness.md](randomness.md)
- **sequential scale**: a colour scale running dark to light in one direction, for "how much". → [colour-scales.md](colour-scales.md)
- **setup**: the build-once step when a sketch starts. → [frame-loop.md](frame-loop.md)
- **shader**: a small program on the graphics chip that answers "where does this corner go?" or "what colour is this pixel?". → [shaders.md](shaders.md)
- **simulation step**: moving a simulation forward by one small slice of time. → [sketches/boidsFlock.md](sketches/boidsFlock.md) (simulation page *(planned)*)
- **smoothstep**: a soft switch from 0 to 1 between two values. → [glsl-basics.md](glsl-basics.md)
- **spectrum**: how loud each pitch in a sound is, from low to high. → [sketches/audioReactiveMesh.md](sketches/audioReactiveMesh.md)
- **state**: the things `setup` built, handed back to `update` on every frame. → [frame-loop.md](frame-loop.md)
- **stereographic projection**: a shadow map of a sphere, as if lit by a lamp at its pole; circles stay circles. → [sketches/hopfFibration.md](sketches/hopfFibration.md)
- **string**: text in quotes. → [js-values-and-variables.md](js-values-and-variables.md)
- **surface**: a shape with no thickness, like a soap film or a sheet. → [sketches/boysSurface.md](sketches/boysSurface.md)
- **swizzling**: picking parts of a GLSL value by letter: `.xy`, `.rgb`, `.xyx`. → [glsl-basics.md](glsl-basics.md)
- **synthesiser**: a machine (here, code) that makes musical tones electronically. → [sketches/generativeSynth.md](sketches/generativeSynth.md)
- **tags**: keywords the gallery search looks through. → [sketch-format.md](sketch-format.md)
- **terminal velocity**: the steady speed a falling thing reaches when air resistance balances gravity. → [sketches/antiAircraftContraception.md](sketches/antiAircraftContraception.md)
- **texture**: a picture a shader can look things up in; often data in disguise. → [textures.md](textures.md)
- **three.js (`THREE`)**: the toolbox for 3D drawing the whole project is built on. → [scene-and-camera.md](scene-and-camera.md)
- **threshold**: the line a value must cross before something happens (a neuron firing, a pixel glowing). → [sketches/flyConnectome.md](sketches/flyConnectome.md)
- **tiling**: covering a floor (or a stranger space) with shapes, no gaps and no overlaps. → [sketches/hyperbolicTiling.md](sketches/hyperbolicTiling.md)
- **tone map**: squeezing very bright colours back into what a screen can show, like a camera does. → [sketches/chatgpt-quantum.md](sketches/chatgpt-quantum.md)
- **topology**: the study of shapes that only cares about what's joined to what, not about size or angles. → [sketches/boysSurface.md](sketches/boysSurface.md)
- **typed array (`Float32Array`)**: a long list holding only numbers, packed for speed. → [js-arrays-and-objects.md](js-arrays-and-objects.md)
- **uniform**: a number handed from JavaScript to a shader, the same for every pixel. → [uniforms.md](uniforms.md)
- **update**: the step that runs on every frame. → [frame-loop.md](frame-loop.md)
- **uTime, uResolution**: the two uniforms every `shader` sketch gets for free: the time and the screen size. → [uniforms.md](uniforms.md)
- **vec2, vec3, vec4**: GLSL bundles of 2, 3 or 4 numbers (positions, colours). → [glsl-basics.md](glsl-basics.md)
- **vector**: an arrow with a direction and a length, stored as numbers (x, y, z). → [sketches/boidsFlock.md](sketches/boidsFlock.md) (math page *(planned)*)
- **velocity**: which way something is heading and how fast. → [sketches/boidsFlock.md](sketches/boidsFlock.md)
- **vertex**: a corner of a triangle in a shape (plural: vertices). → [mesh-geometry-material.md](mesh-geometry-material.md)
- **vertex shader**: the shader that says where each corner lands on screen. → [shaders.md](shaders.md)
- **vignette**: darkening towards the edges of the picture. → [sketches/causticsLight.md](sketches/causticsLight.md)
- **vUv**: a pixel's position on screen, two numbers from 0 to 1. → [shaders.md](shaders.md)
- **Web Worker**: a separate helper inside the browser that runs code in parallel with the drawing. → [sketches/flyConnectome.md](sketches/flyConnectome.md)
